# Carry Skip Adder on FPGA

 Develops 4-bit carry-skip blocks using CARRY4 primitives with LUT-based group-propagate logic across the 256-bit datapath. Implements 256-bit fast adder using FPGA-native CARRY4 chains and performed timing and utilization analysis in Vivado.
